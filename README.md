# 🚀 Thrive-Hub — Affiliate Marketing Management System

**面向跨境电商联盟营销团队的全链路管理系统**  
*Affiliate Marketing Internal Management Platform for Cross-border E-commerce Brands*

---

## 📌 项目简介

Thrive-Hub 是一套专为联盟营销（Affiliate Marketing）服务团队打造的内部协作管理系统，覆盖客户开发、合同管理、任务跟进、推广数据BI、联盟商资源库、客户自助门户六大核心模块，实现跨境电商品牌联盟推广全流程数字化管理。

---

## 🧩 功能架构

```text
Thrive-Hub
├── Dashboard       工作台（全局数据汇总 + 待办）
├── Customers       客户管理（录入、筛选、评级、外链收集）
├── Tasks           任务管理（Kanban看板、优先级、负责人）
├── Contracts       合同管理（创建、多级审核、字段级批注）
├── Reminders       提醒管理（到期通知、类型分类、待办展示）
├── BI Report       推广数据BI（看板、明细、数据上传、多维度筛选）
├── Affiliate Library 联盟资源库（联盟商管理、统计、批量导入）
└── Client Portal   客户门户（公开表单、自助填写、自动建档）
